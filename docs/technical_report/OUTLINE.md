# Technical Report Outline

Mirrors Section 10 of the project guide. Fill each section in before
submission; keep this file as the single source of truth for report structure.

1. Cover page — title, team members, Ghana context, selected organisation
2. Problem statement — assumptions, input-output definitions, system boundaries
3. Dataset description — data dictionary, database schema, sample records
4. System architecture — module design, how components connect
5. Data structures — diagrams, explanations, code snippets for each structure
6. Algorithms — pseudocode and selected Java snippets for each algorithm
7. Correctness evidence — trace tables, invariants, proof sketches, edge-case tests
8. Performance analysis — method, input sizes, raw results tables, graphs, interpretation
9. Database integration — schema, sample records, screenshots, run logs
10. Responsible algorithm selection — when chosen algorithms are appropriate, and when not
11. Individual contribution — each member's contribution + oral-defence prep notes
12. References + Appendices — Cormen, Sedgewick, Goodrich etc. + raw data
